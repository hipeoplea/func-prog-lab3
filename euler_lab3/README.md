# Лабораторная работа №3 — потоковая интерполяция (Elixir)

Цель: повторно реализовать лабораторную работу по вычислительной математике (интерполяция) с упором на потоковую обработку данных, разделение ввода/вывода и функциональную архитектуру.

## Возможности
- **Алгоритмы**: линейная (отрезками) и Ньютонова интерполяции. Можно запускать сразу оба.
- **CLI-настройки**: выбор алгоритмов, шага дискретизации (`--step`), числа точек для Ньютона (`-n`).
- **Потоки**: точки поступают на `stdin` строками `x;y`, `x\ty` или `x y` (по возрастанию `x`). Результат уходит на `stdout` сразу после появления достаточного окна точек.
- **Расширяемость**: алгоритмы вынесены в модули `MyLab3.Interpolation.Linear/Newton`, потоковый конвейер отделён от I/O.

## Архитектура
```
stdin --(парсер)--> поток точек --+--> линейная интерполяция --+
                                 |                            |
                                 +--> Ньютонова интерполяция -+--> stdout
```
- `MyLab3.PointParser` — разбор строк ввода.
- `MyLab3.StreamProcessor` — связывает парсер и набор алгоритмов, обеспечивает потоковый режим.
- `MyLab3.Interpolation.Linear/Newton` — алгоритмы.
- `MyLab3.CLI` — парсинг аргументов, форматирование вывода, точка входа escript.

## Использование
```bash
mix deps.get
mix escript.build          

./my_lab3 --linear --step 0.7 < input.txt
./my_lab3 --linear --newton -n 4 --step 0.5 < input.txt
```
или без сборки escript:
```bash
cat data.txt | mix run -e 'MyLab3.CLI.main(System.argv())' -- --linear --step 0.5
```
Пример (линейная интерполяция, шаг 0.7):
```
$ printf "0 0\n1 1\n2 2\n3 3\n" | ./my_lab3 --linear --step 0.7
linear: 0.0 0.0
linear: 0.7 0.7
linear: 1.4 1.4
linear: 2.1 2.1
linear: 2.8 2.8
linear: 3.0 3.0
```
Пример (Ньютон, 4 точки, шаг 0.5):
```
$ printf "0 0\n1 1\n2 4\n3 9\n" | ./my_lab3 --newton -n 4 --step 0.5
newton: 0.0 0.0
newton: 0.5 0.5
...
```

## Формат ввода
- Каждая строка — две вещественных величины `x` и `y`, разделённые пробелом/табуляцией/`;`.
- Строки сортируются по возрастанию `x`.
- Пустые строки игнорируются; дубликат `x` заменяет предыдущую точку.
